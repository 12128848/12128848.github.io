# CTFHub Git泄露 Index
## 题目信息
- 平台：CTFHub
- 分类：Web - 信息泄露
- 考点：.git/index 索引文件泄露，GitHack 还原暂存区文件
- 描述：开发部署时把.git目录直接放到线上，造成git泄露，使用BugScanTeam GitHack完成解题

## 解题思路
Git 在 `git add` 之后，文件会写入 `.git/index` 索引（暂存区），还没有 commit 提交。这种情况下 git log 看不到记录，只能通过 index 文件恢复出被暂存的文件，拿到flag。

## 复现步骤
1. 开启靶机，访问靶机地址 + `/.git/`，确认.git目录存在
2. 使用 GitHack 脚本拉取并还原仓库
```bash
python GitHack.py http://靶机地址/.git/
3. 工具执行完成后，自动生成 dist 目录，存放还原出来的文件

4. 进入 dist 文件夹，查看提取出来的文件，读取内容得到 flag

漏洞原理

.git/index 是Git的暂存索引文件，记录了已经git add但是还没有git commit的文件内容。如果网站部署时没有删除.git文件夹，攻击者可以下载index文件，还原出暂存文件，造成敏感信息泄露。

修复建议

1. 上线部署代码前，删除 .git 整个文件夹

2. 使用 .gitignore 配置忽略敏感文件

3. Web服务器配置禁止访问 .git 开头的隐藏目录
