可见水印 · 版权声明

适合对外发布的作品，直接把文字或 Logo 压在图片上，起到声明版权、品牌标识、防盗图的作用。

  • 文字 / Logo 两种类型
  • 位置、字号、颜色、透明度、旋转、平铺全可调
  • 导出 PNG / JPG / WebP，质量可控

隐形水印 · 溯源验真

把文字悄悄藏进像素里，肉眼几乎无法察觉。提取时会校验数据完整性，并用感知哈希判断图片是否被改过。

  • 口令加密 + SHA-256 数据校验，防伪造
  • 自动识别嵌入方法，无需手动选择
  • perceptual hash 篡改检测

隐私与安全

所有计算都在你的浏览器里完成，图片不会上传到任何服务器。断开网络也能正常使用。

  • 零后端、零网络请求
  • 关闭页面后数据即消失
  • 开源算法，逻辑透明可审计

方法容量抗 JPEG 压缩抗裁剪推荐场景
LSB · 标准极大不支持弱本地留存、严格篡改检测

DCT · 频域抗压缩中强弱会转 JPG / 压缩后转发

工作原理

嵌入时，工具先把你的消息与可选口令一起做加密混淆，再附加 SHA-256 数据校验值与图片感知哈希（dHash）， 最后把得到的比特流写入像素的最低有效位（LSB）或多个图块中。提取时反读这些比特，校验数据完整性， 并对比当前图片的感知哈希与嵌入时记录的哈希 —— 一旦图片被修改，哈希就会产生偏差，从而判定"疑似篡改"。
